## 4. Variables - Storing Information

### What are Variables?
Variables are like labeled boxes where you store information. You can put things in, take them out, and change what's inside.

```javascript
// Creating variables
let myName = "Alex";
let myAge = 25;
let isStudent = true;

// Using variables
console.log("Hi, I'm " + myName);
```

### Types of Variables:

#### let - Can Change
```javascript
let score = 10;
console.log(score); // 10

score = 20; // Changing the value
console.log(score); // 20
```

#### const - Cannot Change
```javascript
const birthYear = 1995;
console.log(birthYear); // 1995

// birthYear = 1996; // This would cause an error!
```

#### var - Old Way (Avoid for Now)
```javascript
var oldStyle = "Don't use this yet";
```

### Variable Naming Rules:
```javascript
// ✅ Good names
let firstName = "John";
let userAge = 30;
let isLoggedIn = true;
let numberOfLikes = 150;

// ❌ Bad names
let x = "John"; // Not descriptive
let 123name = "John"; // Can't start with number
let first-name = "John"; // Can't use hyphens
```

## 6. Basic Operations - Making Things Happen

### Math Operations
```javascript
let a = 10;
let b = 3;

console.log(a + b);  // 13 (addition)
console.log(a - b);  // 7  (subtraction)
```

## 8. Loops - Repeating Actions

### for Loop (When You Know How Many Times)
```javascript
// Count from 1 to 5
for (let i = 1; i <= 5; i++) {
    console.log("Count:", i);
}
// Output: Count: 1, Count: 2, Count: 3, Count: 4, Count: 5

// Loop through an array
let colors = ["red", "green", "blue"];
for (let i = 0; i < colors.length; i++) {
    console.log("Color:", colors[i]);
}
```

### while Loop (When You Don't Know How Many Times)
```javascript
let password = "";
let attempts = 0;

while (password !== "secret123" && attempts < 3) {
    password = prompt("Enter password:");
    attempts++;
    
    if (password === "secret123") {
        console.log("Access granted!");
    } else {
        console.log("Wrong password. Try again.");
    }
}
```

### for...of Loop (Easy Array Looping)
```javascript
let fruits = ["apple", "banana", "orange"];

for (let fruit of fruits) {
    console.log("I like", fruit);
}
// Output: I like apple, I like banana, I like orange
```

## 9. Functions - Reusable Code Blocks

### What are Functions?
Functions are like recipes - you write them once and use them many times. They take ingredients (inputs) and produce a dish (output).

### Basic Function
```javascript
function sayHello() {
    console.log("Hello, World!");
}

// Using (calling) the function
sayHello(); // Output: Hello, World!
```

### Functions with Parameters
```javascript
function greetPerson(name) {
    console.log("Hello, " + name + "!");
}

greetPerson("Alice"); // Output: Hello, Alice!
greetPerson("Bob");   // Output: Hello, Bob!
```

### Functions that Return Values
```javascript
function addNumbers(a, b) {
    return a + b;
}

let result = addNumbers(5, 3);
console.log(result); // 8

let sum = addNumbers(10, 20);
console.log("The sum is:", sum); // The sum is: 30
```

### Real-World Function Example
```javascript
function calculateTip(billAmount, tipPercentage) {
    let tip = billAmount * (tipPercentage / 100);
    let total = billAmount + tip;
    
    return {
        tip: tip,
        total: total
    };
}

let restaurant = calculateTip(50, 15);
console.log("Tip: $" + restaurant.tip);     // Tip: $7.5
console.log("Total: $" + restaurant.total); // Total: $57.5
```

## 12. Variable Declarations - All Ways to Declare Variables

### Complete Overview of Variable Declaration Methods

JavaScript has evolved over time, and there are actually several ways to declare variables. Let's cover ALL of them, from legacy to modern:

#### var - The Original Way (ES5 and earlier)
```javascript
var name = "John";
var age = 25;
var age = 30; // ✅ Can redeclare (but confusing and error-prone)

// Function-scoped (not block-scoped)
function example() {
    var x = 1;
    if (true) {
        var x = 2; // Same variable! Overwrites the previous one
        console.log(x); // 2
    }
    console.log(x); // 2 (changed everywhere in the function)
}

// Hoisting behavior - var declarations are "hoisted"
console.log(hoistedVar); // undefined (not error!)
var hoistedVar = "I'm hoisted";

// Problems with var
for (var i = 0; i < 3; i++) {
    setTimeout(function() {
        console.log(i); // Prints 3, 3, 3 (not 0, 1, 2!)
    }, 100);
}
```

#### let - Modern Mutable Variables (ES6/ES2015)
```javascript
let score = 100;
score = 150; // ✅ Can change value
// let score = 200; // ❌ Cannot redeclare in same scope

// Block-scoped (respects if statements, loops, etc.)
function betterExample() {
    let y = 1;
    if (true) {
        let y = 2; // Different variable! New scope
        console.log(y); // 2
    }
    console.log(y); // 1 (unchanged)
}

// Temporal Dead Zone - cannot use before declaration
// console.log(letVar); // ❌ ReferenceError!
let letVar = "I must be declared first";

// Fixes the loop problem
for (let i = 0; i < 3; i++) {
    setTimeout(function() {
        console.log(i); // Prints 0, 1, 2 correctly!
    }, 100);
}
```

#### const - Immutable References (ES6/ES2015)
```javascript
const PI = 3.14159;
const USER_NAME = "admin";
// PI = 3.14; // ❌ Cannot change value
// const PI = 3.14; // ❌ Cannot redeclare

// Must be initialized when declared
// const uninitialized; // ❌ SyntaxError!

// Special case: Objects and arrays (contents can change)
const person = { name: "John", age: 30 };
person.age = 31; // ✅ Can modify properties
person.city = "New York"; // ✅ Can add properties
// person = {}; // ❌ Cannot reassign entire object

const fruits = ["apple", "banana"];
fruits.push("orange"); // ✅ Can modify array contents
fruits[0] = "grape"; // ✅ Can change array elements
// fruits = []; // ❌ Cannot reassign entire array
```

#### Implicit Global Variables (Legacy - NEVER USE)
```javascript
// Without any declaration keyword (creates global variable)
function badExample() {
    implicitGlobal = "I'm accidentally global!"; // ❌ VERY BAD!
}
badExample();
console.log(implicitGlobal); // "I'm accidentally global!"

// This pollutes the global scope and causes bugs
// Always use "use strict"; to prevent this
```

#### Function Parameters (Another way to create variables)
```javascript
function greet(userName, userAge) { // userName and userAge are variables
    console.log(`Hello ${userName}, you are ${userAge} years old`);
    // userName and userAge exist only within this function
}

// Default parameters (ES6)
function greetWithDefault(userName = "Guest", userAge = 0) {
    console.log(`Hello ${userName}, you are ${userAge} years old`);
}
```

#### Destructuring Assignment (ES6 - Advanced but Important)
```javascript
// Array destructuring - creates variables from array elements
const colors = ["red", "green", "blue"];
const [primary, secondary, tertiary] = colors;
console.log(primary); // "red"
console.log(secondary); // "green"

// Object destructuring - creates variables from object properties
const person = { name: "Alice", age: 30, city: "Paris" };
const { name, age, city } = person;
console.log(name); // "Alice"
console.log(age); // 30

// With different variable names
const { name: personName, age: personAge } = person;
console.log(personName); // "Alice"
```

#### Using Statement (Creates variables in specific scope)
```javascript
// Creates variables from object properties in local scope
const config = { host: "localhost", port: 3000, ssl: true };

// with statement (DEPRECATED - don't use in modern code)
// with (config) {
//     console.log(host); // "localhost"
//     console.log(port); // 3000
// }

// Modern alternative using destructuring
const { host, port, ssl } = config;
console.log(host); // "localhost"
console.log(port); // 3000
```

### Comparison Table

| Declaration | Scope | Hoisting | Can Redeclare | Can Reassign | Initialized |
|-------------|-------|----------|---------------|--------------|-------------|
| `var` | Function | Yes (undefined) | ✅ Yes | ✅ Yes | No |
| `let` | Block | Yes (TDZ*) | ❌ No | ✅ Yes | No |
| `const` | Block | Yes (TDZ*) | ❌ No | ❌ No | Required |
| Implicit | Global | No | ✅ Yes | ✅ Yes | No |

*TDZ = Temporal Dead Zone (cannot access before declaration)

### When to Use Each (Best Practices):

#### ✅ **Modern Recommended Order:**
1. **`const`** - Default choice (95% of the time)
2. **`let`** - When you need to reassign the variable
3. **`var`** - Only when working with legacy code or need function scoping
4. **Never use implicit globals**

```javascript
// ✅ Good modern code
const userName = "Alice"; // Won't change
const users = []; // Array contents can change, reference cannot
let currentIndex = 0; // Will be reassigned in a loop
let isLoggedIn = false; // Will change based on user action

for (let i = 0; i < users.length; i++) { // Loop variable
    // Process users
}

// ❌ Old style (still works but not recommended)
var userName = "Alice";
var users = [];
var currentIndex = 0;
var isLoggedIn = false;

for (var i = 0; i < users.length; i++) {
    // Process users
}
```

### Common Mistakes and How to Avoid Them:

#### Mistake 1: Using var in loops
```javascript
// ❌ Problem with var
for (var i = 0; i < 3; i++) {
    setTimeout(() => console.log(i), 100); // Prints: 3, 3, 3
}

// ✅ Fixed with let
for (let i = 0; i < 3; i++) {
    setTimeout(() => console.log(i), 100); // Prints: 0, 1, 2
}
```

#### Mistake 2: Forgetting const for objects
```javascript
// ❌ Unnecessary mutability
let config = { theme: "dark", lang: "en" };
config.theme = "light"; // Could accidentally reassign entire object

// ✅ Protect the reference
const config = { theme: "dark", lang: "en" };
config.theme = "light"; // Can still modify properties
// config = {}; // ❌ Cannot reassign - prevents bugs
```

#### Mistake 3: Not understanding hoisting
```javascript
// ❌ Confusing behavior with var
console.log(x); // undefined (not error, but confusing)
var x = 5;

// ✅ Clear behavior with let/const
// console.log(y); // ❌ ReferenceError (clear error)
let y = 5;
```

### Why This History Matters:
- **Legacy codebases**: You'll encounter `var` in older code
- **Browser compatibility**: Older browsers only support `var`
- **Understanding errors**: Knowing all methods helps debug issues
- **Code migration**: You might need to update old code to modern standards
- **Interview questions**: Employers often ask about these differences

### The Evolution Timeline:
- **1995**: JavaScript created with `var`
- **2015**: ES6 introduced `let` and `const`
- **2015+**: Modern best practices favor `const` and `let`
- **Today**: `var` is legacy but still functional

## 13. Arithmetic Operators and Advanced Usage

### Basic Arithmetic Operators
```javascript
let a = 10;
let b = 3;

console.log(a + b);  // 13 (addition)
console.log(a - b);  // 7  (subtraction)
console.log(a * b);  // 30 (multiplication)
console.log(a / b);  // 3.333... (division)
console.log(a % b);  // 1 (modulo/remainder)
console.log(a ** b); // 1000 (exponentiation - a to the power of b)
```

### Assignment Operators
```javascript
let score = 100;

score += 10;  // score = score + 10 (now 110)
score -= 5;   // score = score - 5 (now 105)
score *= 2;   // score = score * 2 (now 210)
score /= 3;   // score = score / 3 (now 70)
score %= 7;   // score = score % 7 (now 0)
score **= 2;  // score = score ** 2 (now 0)

console.log(score); // 0
```

### Increment and Decrement
```javascript
let count = 5;

// Pre-increment: increment first, then use
console.log(++count); // 6 (count becomes 6, then logs 6)

// Post-increment: use first, then increment
console.log(count++); // 6 (logs 6, then count becomes 7)
console.log(count);   // 7

// Pre-decrement: decrement first, then use
console.log(--count); // 6 (count becomes 6, then logs 6)

// Post-decrement: use first, then decrement
console.log(count--); // 6 (logs 6, then count becomes 5)
console.log(count);   // 5
```

### Operator Precedence
```javascript
let result = 2 + 3 * 4;     // 14 (not 20, multiplication first)
let result2 = (2 + 3) * 4;  // 20 (parentheses override precedence)

let complex = 2 + 3 * 4 ** 2; // 2 + 3 * 16 = 2 + 48 = 50
```

## 14. Advanced Loop Concepts

### Break and Continue Statements

#### break - Exit the Loop
```javascript
// Finding the first even number
for (let i = 1; i <= 10; i++) {
    if (i % 2 === 0) {
        console.log("First even number:", i);
        break; // Exit the loop immediately
    }
}
// Output: First even number: 2

// Break in nested loops
for (let i = 1; i <= 3; i++) {
    for (let j = 1; j <= 3; j++) {
        if (i === 2 && j === 2) {
            break; // Only breaks inner loop
        }
        console.log(i, j);
    }
}
```

#### continue - Skip to Next Iteration
```javascript
// Skip odd numbers
for (let i = 1; i <= 10; i++) {
    if (i % 2 === 1) {
        continue; // Skip rest of loop body, go to next iteration
    }
    console.log("Even number:", i);
}
// Output: Even number: 2, Even number: 4, etc.

// Skip empty strings
let words = ["hello", "", "world", "", "javascript"];
for (let word of words) {
    if (word === "") {
        continue; // Skip empty strings
    }
    console.log(word.toUpperCase());
}
// Output: HELLO, WORLD, JAVASCRIPT
```

### Practical Examples
```javascript
// User input validation with break
let attempts = 0;
while (attempts < 3) {
    let password = prompt("Enter password:");
    attempts++;
    
    if (password === "secret123") {
        console.log("Access granted!");
        break; // Exit loop on success
    }
    
    if (attempts === 3) {
        console.log("Too many attempts. Access denied.");
    } else {
        console.log(`Wrong password. ${3 - attempts} attempts remaining.`);
    }
}

// Processing arrays with continue
let numbers = [1, -2, 3, -4, 5, -6];
let positiveSum = 0;

for (let number of numbers) {
    if (number < 0) {
        continue; // Skip negative numbers
    }
    positiveSum += number;
}
console.log("Sum of positive numbers:", positiveSum); // 9
```

## 15. Functions Without Return Statements

### What Happens When Functions Don't Return?

```javascript
// Function without return statement
function greetUser(name) {
    console.log("Hello, " + name + "!");
    // No return statement
}

let result = greetUser("Alice");
console.log(result); // undefined

// The function still does something (side effect)
// But doesn't give back a value
```

## 16. Scope and Variables Deep Dive

### Understanding Scope

Scope determines where variables can be accessed in your code:

```javascript
// Global scope - accessible everywhere
let globalVariable = "I'm global";

function outerFunction() {
    // Function scope - accessible within this function
    let outerVariable = "I'm in outer function";
    
    function innerFunction() {
        // Inner function scope
        let innerVariable = "I'm in inner function";
        
        console.log(globalVariable);  // ✅ Can access global
        console.log(outerVariable);   // ✅ Can access outer
        console.log(innerVariable);   // ✅ Can access inner
    }
    
    innerFunction();
    console.log(globalVariable);  // ✅ Can access global
    console.log(outerVariable);   // ✅ Can access outer
    // console.log(innerVariable); // ❌ Cannot access inner scope
}

outerFunction();
console.log(globalVariable);  // ✅ Can access global
// console.log(outerVariable); // ❌ Cannot access function scope
```

### Block Scope with let and const
```javascript
if (true) {
    let blockVariable = "I'm in a block";
    const blockConstant = "I'm also in a block";
    var functionVariable = "I'm function-scoped";
}

// console.log(blockVariable);   // ❌ Error - let is block-scoped
// console.log(blockConstant);   // ❌ Error - const is block-scoped
console.log(functionVariable);   // ✅ Works - var is function-scoped

// Same with loops
for (let i = 0; i < 3; i++) {
    let loopVariable = "Loop iteration " + i;
}
// console.log(i);            // ❌ Error - i is block-scoped
// console.log(loopVariable); // ❌ Error - loopVariable is block-scoped
```

```javascript
function readFile() {
    const fileInput = document.getElementById('fileInput');
    const file = fileInput.files[0];
    
    if (!file) {
        alert('Please select a file');
        return;
    }
```

#### Reading JSON Files
```javascript
function readJSONFile() {
    const fileInput = document.getElementById('fileInput');
    const file = fileInput.files[0];
    
    if (!file) return;
    
    const reader = new FileReader();
    
    reader.onload = function(event) {
        try {
            const jsonData = JSON.parse(event.target.result);
            console.log('JSON data:', jsonData);
            displayData(jsonData);
        } catch (error) {
            console.error('Invalid JSON file:', error);
        }
    };
    
    reader.readAsText(file);
}

function displayData(data) {
    // Display JSON data on the page
    const contentDiv = document.getElementById('fileContent');
    contentDiv.innerHTML = '<pre>' + JSON.stringify(data, null, 2) + '</pre>';
}
```

### Basic Module Concepts (ES6 Modules)

```javascript
// math.js - utility functions
export function add(a, b) {
    return a + b;
}

export function multiply(a, b) {
    return a * b;
}

export const PI = 3.14159;

// Default export
export default function calculator(operation, a, b) {
    switch(operation) {
        case 'add': return add(a, b);
        case 'multiply': return multiply(a, b);
        default: return 0;
    }
}
```

#### Using the Module (main.js)

```javascript
console.log(calculator('add', 10, 20));      // 30
console.log(calculator('multiply', 6, 7));   // 42
```

### Object Methods
```javascript
let calculator = {
    result: 0,

        this.result += number;
        return this; // Enable method chaining
    },

        this.result -= number;
        return this;
    },

        return this;
```

## 19. Common Beginner Mistakes and How to Avoid Them

### 1. Forgetting Semicolons
```javascript
// ❌ Can cause issues

let age = 25

// ✅ Better practice
let name = "John";
let age = 25;
```

### 2. Case Sensitivity
```javascript

console.log(myvariable); // ❌ Error! JavaScript is case-sensitive
console.log(myVariable); // ✅ Correct
```

### 3. Comparing vs Assigning
```javascript
let x = 10;

if (x = 5) { // ❌ This assigns 5 to x (always true)
    console.log("This always runs");
}

if (x === 5) { // ✅ This compares x to 5
    console.log("This only runs if x equals 5");
}
```

### 4. Understanding Scope
```javascript

}
```
