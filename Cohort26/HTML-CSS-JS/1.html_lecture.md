## 1. The HTML5 Foundation - Your Page's Blueprint

Think of HTML like the skeleton of your webpage. Every HTML page needs this basic structure:

```html
<!DOCTYPE html>
<html lang="en" dir="ltr">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover">
    <meta name="description" content="Techium is a digital agency">
    <title>Homepage - Techium</title>
    <link rel="icon" type="image/x-icon" href="./favicon.ico">
    <link rel="icon" type="image/png" href="./favicon.png">
  </head>
  <body>
    <!-- Your actual content goes here -->
  </body>
</html>
```

### Breaking Down the `<head>` Section

The `<head>` is like the "behind-the-scenes" information that browsers and search engines need:

- **`<!DOCTYPE html>`** - Tells the browser "this is an HTML5 document"
- **`<html lang="en" dir="ltr">`** - Sets the language to English and text direction left-to-right
- **`<meta charset="utf-8">`** - Allows your page to display characters from any language
- **`<meta name="viewport"...>`** - Makes your page look good on mobile devices
- **`<meta name="description"...>`** - Tells search engines what your page is about
- **`<title>`** - What appears in the browser tab
- **`<link rel="icon"...>`** - The small icon that appears in the browser tab

## 2. Semantic HTML - Tags That Have Meaning

HTML5 gives us special tags that describe what content they contain. Think of them like labels on boxes:

```html
<header>
  <!-- Logo, site title, main navigation -->
</header>

<nav>
  <!-- Navigation menu links -->
</nav>

<main>
  <!-- The main content of your page -->
</main>

<section>
  <!-- A distinct section of content -->
</section>

<article>
  <!-- A complete piece of content (like a blog post) -->
</article>

<aside>
  <!-- Side content like a sidebar -->
</aside>

<footer>
  <!-- Footer information -->
</footer>
```

**Why use semantic tags?** They help screen readers understand your content and make your code easier to read and maintain.

---

## 3. Headings - Creating a Clear Hierarchy

Headings are like the outline of your page:

```html
<h1>My Website</h1>           <!-- Main title (only one per page) -->
  <h2>About Us</h2>           <!-- Major section -->
    <h3>Our Team</h3>         <!-- Subsection -->
      <h4>John Smith</h4>     <!-- Sub-subsection -->
```

**Golden Rules:**
- Use only one `<h1>` per page
- Don't skip levels (don't jump from `<h2>` to `<h5>`)
- Use headings for structure, not just to make text bigger

## 4. Organizing Content with Lists

Lists help organize information clearly:

### Unordered Lists (bullet points)
```html
<ul>
  <li>Web Design</li>
  <li>Mobile Development</li>
  <li>SEO Services</li>
</ul>
```

### Ordered Lists (numbered)
```html
<ol>
  <li>Plan your website</li>
  <li>Design the layout</li>
  <li>Write the code</li>
  <li>Test and launch</li>
</ol>
```

### Definition Lists (terms and definitions)
```html

  <dt>HTML</dt>
  <dd>HyperText Markup Language - the structure of web pages</dd>
  <dt>CSS</dt>
  <dd>Cascading Style Sheets - makes web pages look beautiful</dd>
</dl>
```

## 6. Adding Media to Your Pages

Media elements make your website engaging and informative. Let's dive deep into how to properly embed images, videos, and audio.

### Images - The Foundation of Visual Content

The `<img>` tag is a **self-closing tag** that embeds images into your webpage. Understanding its attributes is crucial for web development.

```html
<img src="images/team-photo.jpg" 
     alt="Our team at the office" 
     width="400" 
     height="300"
     loading="lazy"
     title="Hover text appears here">
```

#### Essential Image Attributes Explained:

**`src` (source) - Required**
- The path to your image file
- Can be relative (`images/photo.jpg`) or absolute (`https://example.com/photo.jpg`)
- Common formats: `.jpg`, `.png`, `.gif`, `.webp`, `.svg`

**`alt` (alternative text) - Required for accessibility**
- Describes the image for screen readers and when images fail to load
- Should be descriptive but concise
- For decorative images, use `alt=""` (empty but present)
- Example: `alt="Team of 5 developers working on laptops in a modern office"`

**`width` and `height` - Highly recommended**
- Specifies image dimensions in pixels
- Prevents layout shift as the page loads
- Browsers can reserve space before the image loads
- Don't use to resize images - resize the actual image file instead

**`loading` - Performance optimization**
- `loading="lazy"` - Loads image only when it's about to appear on screen
- `loading="eager"` - Loads immediately (default)
- Use lazy loading for images below the fold

**`title` - Optional**
- Provides additional information that appears on hover
- Different from `alt` - this is for extra context, not accessibility

#### Image Best Practices:

1. **File Organization**: Keep images in a dedicated folder (`images/` or `assets/`)
2. **File Naming**: Use descriptive, lowercase names with hyphens (`team-photo-2024.jpg`)
3. **File Formats**:
   - JPG: Photos and complex images
   - PNG: Images with transparency or simple graphics
   - WebP: Modern format, smaller file sizes
   - SVG: Vector graphics and icons

```html
<!-- Good example -->
<img src="images/product-showcase.jpg" 
     alt="iPhone 15 Pro displaying our mobile app interface" 
     width="600" 
     height="400"
     loading="lazy">

<!-- Bad example -->
<img src="photo.jpg" alt="image">
```

### Videos - Rich Media Content

The `<video>` element provides native video playback without plugins. It's much more powerful than you might think.

```html
<video controls loop poster="video-thumbnail.jpg" preload="metadata">
  <source src="company-intro.mp4" type="video/mp4">
  <source src="company-intro.webm" type="video/webm">
  <track kind="subtitles" src="subtitles.vtt" srclang="en" label="English">
  Your browser doesn't support this video format.
</video>
```

#### Video Attributes Deep Dive:

**`controls` - User interface**
- Adds play/pause, volume, timeline controls
- Remove if you want custom controls via JavaScript

**`loop` - Playback behavior**
- Video restarts automatically when it ends
- Useful for background videos or demos

**`autoplay` - Automatic playback**
- `autoplay muted` - Plays automatically without sound (most browsers require this)
- Avoid `autoplay` with sound - it's poor user experience

**`poster` - Thumbnail image**
- Image shown before video plays
- Should represent the video content
- Same dimensions as video for best appearance

**`preload` - Loading strategy**
- `preload="none"` - Don't preload anything
- `preload="metadata"` - Preload video dimensions and duration
- `preload="auto"` - Preload entire video (use sparingly)

**`muted` - Audio state**
- Required for autoplay in most browsers
- Can be unmuted by user interaction

#### Multiple Video Sources:
```html
<video controls>
  <source src="video.mp4" type="video/mp4">
  <source src="video.webm" type="video/webm">
  <source src="video.ogg" type="video/ogg">
  <!-- Browser will use the first supported format -->
</video>
```

### Audio - Sound and Music

The `<audio>` element works similarly to video but for audio content.

```html
<audio controls preload="none">
  <source src="podcast-episode-1.mp3" type="audio/mpeg">
  <source src="podcast-episode-1.ogg" type="audio/ogg">
  <source src="podcast-episode-1.wav" type="audio/wav">
  Your browser doesn't support audio playback.
</audio>
```

#### Audio Attributes:

**`controls` - Essential for user interaction**
- Without this, users can't control playback
- Only omit if you're using JavaScript for custom controls

**`preload` - Loading behavior**
- `preload="none"` - Good for podcasts or long audio
- `preload="metadata"` - Loads duration and basic info
- `preload="auto"` - Preloads entire file

**`loop` and `autoplay`** - Work the same as video
- Be very careful with autoplay audio
- Most browsers block autoplay audio entirely

#### Audio Format Recommendations:
- **MP3**: Universal compatibility, good compression
- **OGG**: Open source, good quality
- **WAV**: Uncompressed, large files but highest quality

### Responsive Media Considerations

For modern web development, consider responsive images:

```html
<picture>
  <source media="(min-width: 800px)" srcset="large-image.jpg">
  <source media="(min-width: 400px)" srcset="medium-image.jpg">
  <img src="small-image.jpg" alt="Responsive image description">
</picture>
```

## 7. Creating Tables for Data

Tables are specifically designed for displaying **tabular data** - information that naturally fits into rows and columns. They should NOT be used for layout purposes.

### When to Use Tables:
- Financial data, statistics, comparisons
- Schedules, calendars, spreadsheet-like data
- Any data with relationships between rows and columns

### Table Structure Explained:

```html
<table>
  <caption>Monthly Sales Report 2024</caption>
  <thead>
    <tr>
      <th scope="col">Month</th>
      <th scope="col">Revenue</th>
      <th scope="col">Expenses</th>
      <th scope="col">Profit</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">January</th>
      <td>$15,000</td>
      <td>$8,000</td>
      <td>$7,000</td>
    </tr>
    <tr>
      <th scope="row">February</th>
      <td>$18,000</td>
      <td>$9,000</td>
      <td>$9,000</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <th scope="row">Total</th>
      <td>$33,000</td>
      <td>$17,000</td>
      <td>$16,000</td>
    </tr>
  </tfoot>
</table>
```

#### Table Elements Breakdown:

**`<table>` - The container**
- Wraps all table content
- Can be styled with CSS for borders, spacing, etc.

**`<caption>` - Table title**
- Provides context for the entire table
- Important for accessibility
- Appears above the table by default

**`<thead>` - Table header**
- Contains column headers
- Browsers can repeat this when printing long tables

**`<tbody>` - Table body**
- Contains the main data rows
- Can have multiple tbody sections

**`<tfoot>` - Table footer**
- Contains summary information
- Totals, averages, or notes

**`<tr>` - Table row**
- Each row of data
- Contains `<th>` or `<td>` elements

**`<th>` - Header cell**
- Column or row headers
- `scope="col"` for column headers
- `scope="row"` for row headers
- Makes tables accessible to screen readers

**`<td>` - Data cell**
- Regular data content
- Can contain any HTML content

#### Advanced Table Features:

**Spanning Cells:**
```html
<td colspan="2">This cell spans 2 columns</td>
<td rowspan="3">This cell spans 3 rows</td>
```

**Accessible Table:**
```html
<table>
  <caption>Company Performance Q1 2024</caption>
  <thead>
    <tr>
      <th scope="col" id="month">Month</th>
      <th scope="col" id="sales">Sales</th>
      <th scope="col" id="growth">Growth %</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row" headers="month">January</th>
      <td headers="sales">$50,000</td>
      <td headers="growth">+15%</td>
    </tr>
  </tbody>
</table>
```

## 8. Creating Links and Navigation

Links are the foundation of the web - they connect pages and create the web's interconnected nature.

### Types of Links and Their Purposes:

#### Internal Links (Anchor Links)
Navigate within the same page:
```html
<a href="#services">Jump to Services Section</a>
<a href="#top">Back to Top</a>

<!-- Target element needs an id -->
<section id="services">
  <h2>Our Services</h2>
</section>
```

#### Relative Links (Same Website)
Navigate to other pages on your site:
```html
<a href="about.html">About Us</a>
<a href="pages/contact.html">Contact</a>
<a href="../index.html">Back to Home</a>
```

#### Absolute Links (External Sites)
Navigate to other websites:
```html
<a href="https://www.example.com" target="_blank" rel="noopener noreferrer">
  Visit Example.com
</a>
```

#### Special Link Types:

**Email Links:**
```html
<a href="mailto:contact@techium.com?subject=Hello&body=I'm interested in your services">
  Email Us
</a>
```

**Phone Links:**
```html
<a href="tel:+1234567890">Call Us: (123) 456-7890</a>
```

**Download Links:**
```html
<a href="brochure.pdf" download="Techium-Brochure.pdf">
  Download Our Brochure
</a>
```

### Link Attributes Explained:

**`href` - The destination**
- Required for functional links
- Can be URL, file path, email, phone number, or anchor

**`target` - Where to open the link**
- `target="_blank"` - Opens in new tab/window
- `target="_self"` - Opens in same tab (default)
- `target="_parent"` - Opens in parent frame
- `target="_top"` - Opens in full window

**`rel` - Relationship to linked content**
- `rel="noopener noreferrer"` - Security for external links
- `rel="nofollow"` - Don't pass SEO value
- `rel="alternate"` - Alternative version

**`download` - Force download**
- Makes browsers download instead of navigate
- Optional filename for the downloaded file

### Navigation Best Practices:

```html
<nav aria-label="Main navigation">
  <ul>
    <li><a href="index.html" aria-current="page">Home</a></li>
    <li><a href="about.html">About</a></li>
    <li><a href="services.html">Services</a></li>
    <li><a href="contact.html">Contact</a></li>
  </ul>
</nav>
```

## 9. Embedding External Content

The `<iframe>` element lets you embed content from other websites directly into your page.

### iframe Fundamentals:

```html
<iframe 
  src="https://www.youtube.com/embed/41N6bKO-NVI"
  width="560" 
  height="315"
  title="Holberton School Introduction Video"
  frameborder="0"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
  allowfullscreen>
  Your browser doesn't support embedded videos.
</iframe>
```

#### iframe Attributes Detailed:

**`src` - The embedded content URL**
- Must be the embed URL, not the regular page URL
- YouTube: `https://www.youtube.com/embed/VIDEO_ID`
- Google Maps: Use the embed code from Maps

**`width` and `height` - Dimensions**
- Can be pixels or percentages
- Consider responsive design

**`title` - Accessibility**
- Describes the embedded content
- Essential for screen readers

**`frameborder` - Border styling**
- `frameborder="0"` removes the border
- Better to use CSS for styling

**`allow` - Feature permissions**
- Controls what the embedded content can do
- `autoplay`, `camera`, `microphone`, `geolocation`, etc.

**`allowfullscreen` - Fullscreen capability**
- Allows content to expand to fullscreen
- Common for videos

### Common iframe Use Cases:

**YouTube Videos:**
```html
<iframe 
  src="https://www.youtube.com/embed/VIDEO_ID"
  width="560" height="315"
  title="Video Title"
  allow="autoplay; encrypted-media"
  allowfullscreen>
</iframe>
```

**Google Maps:**
```html
<iframe 
  src="https://www.google.com/maps/embed?pb=..."
  width="600" height="450"
  title="Office Location"
  allowfullscreen>
</iframe>
```

**Social Media Posts:**
```html
<iframe 
  src="https://www.facebook.com/plugins/post.php?href=..."
  width="500" height="600"
  title="Facebook Post"
  scrolling="no">
</iframe>
```

### Security Considerations:

**Sandbox Attribute:**
```html
<iframe 
  src="untrusted-content.html"
  sandbox="allow-scripts allow-same-origin"
  title="Sandboxed Content">
</iframe>
```

**Loading Attribute:**
```html
<iframe 
  src="https://example.com/widget"
  loading="lazy"
  title="Widget">
</iframe>
```

### Making iframes Responsive:

```html
<div class="iframe-container">
  <iframe 
    src="https://www.youtube.com/embed/VIDEO_ID"
    title="Video Title"
    allowfullscreen>
  </iframe>
</div>
```

You'll later learn CSS to make this responsive:
```css
.iframe-container {
  position: relative;
  padding-bottom: 56.25%; /* 16:9 aspect ratio */
  height: 0;
}

.iframe-container iframe {
  position: absolute;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
}
```

## 10. Best Practices for Beginners

### Keep Your Code Organized
Use comments to label sections:
```html
<!-- Navigation Section -->
<nav>
  <!-- navigation content -->
</nav>

<!-- Main Content -->
<main>
  <!-- main content -->
</main>

<!-- Footer -->
<footer>
  <!-- footer content -->
</footer>
```

### Accessibility Checklist
- ✅ Use proper heading hierarchy (h1, h2, h3...)
- ✅ Add alt text to all images
- ✅ Use semantic HTML tags
- ✅ Make sure your content makes sense without CSS

## 11. Putting It All Together

Here's a simple example combining everything:

```html
<!DOCTYPE html>
<html lang="en" dir="ltr">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Website</title>
  </head>
  <body>
    <header>
      <h1>Welcome to My Website</h1>
      <nav>
        <ul>
          <li><a href="#about">About</a></li>
          <li><a href="#services">Services</a></li>
          <li><a href="#contact">Contact</a></li>
        </ul>
      </nav>
    </header>

    <main>
      <section id="about">
        <h2>About Us</h2>
        <p>We create amazing websites for businesses.</p>
        <img src="team.jpg" alt="Our team working together">
      </section>

      <section id="services">
        <h2>Our Services</h2>
        <ul>
          <li>Web Design</li>
          <li>Mobile Apps</li>
          <li>SEO</li>
        </ul>
      </section>
    </main>

    <footer>
      <p>&copy; 2024 My Website. All rights reserved.</p>
    </footer>
  </body>
</html>
```
